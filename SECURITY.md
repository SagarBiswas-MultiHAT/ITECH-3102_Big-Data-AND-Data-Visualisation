# Security, Academic Integrity and IP Policy

## Academic Integrity and Plagiarism Notice

This project represents original academic coursework completed for **ITECH3102: Big Data and Data Visualisation** at **Federation University Australia**.

### Turnitin and Plagiarism Warning
- All reports, design proposals, and analytical texts in this repository are publicly indexed in web-crawler search engines and academic similarity databases, including **Turnitin**.
- Any attempt by current or future students to submit parts of this repository as their own academic work will result in immediate plagiarism flags for collusion and academic misconduct.

---

## Reporting Plagiarism or Copyright Infringement

If you discover an unauthorized copy, resale, or plagiarism of this repository on commercial websites, essay mills, or academic platforms, please submit a report:

1. Open an issue on this repository labeled `[IP Violation]`.
2. Include the URL of the infringing content and the date of discovery.
3. Appropriate DMCA takedown requests and institutional academic misconduct notifications will be dispatched.

---

## Vulnerability Reporting

If you identify a security vulnerability within the web implementations or local server configurations, please open a private GitHub advisory or contact the maintainer directly through GitHub.
